Sobre o Projeto

Banco de Dados

  • Banco usado: H2 (arquivo local)
  • URL de acesso: jdbc:h2:file:./src/main/resources/db/banco-dados-h2
  • Console H2: http://localhost:8080/h2-console
  • Usuário: sa
  • Senha: (vazia)
  • Hibernate ddl-auto: create

Configuração do Projeto

  • Java version: 17
  • Spring Boot version: 3.4.4
  • Arquitetura: Hexagonal
  • OpenAPI: usado para geração de APIs
  • Lombok: sim
  • Logs configurados em nível INFO
  • Swagger UI: /swagger-ui.html

Dependências do Projeto

  • spring-boot-starter-web: Base para criar APIs REST.
  • spring-boot-starter-data-jpa: Persistência de dados usando JPA/Hibernate.
  • com.h2database:h2: Banco de dados em memória/arquivo para desenvolvimento e testes.
  • springdoc-openapi-starter-webmvc-ui: Geração automática da documentação da API.
  • lombok: Reduz boilerplate com getters, setters, builders e construtores automáticos.
  • log4j-api & log4j-core: Configuração e controle de logs do sistema.
  • hibernate-validator: Valida dados de entidades JPA.
  • javax.validation & javax.annotation-api: Suporte para validações e anotações padrão do Java.

Estrutura Hexagonal

  • app: Serviços e casos de uso.
  • domain: Entidades e regras de negócio.
  • infra: Repositórios, integrações externas e implementação de interfaces.

Informações da API

  • Endpoints principais: /product, /cooperator, /tax-receipt, /tax-receipt-item
  • Operações suportadas: CRUD completo
  • Paginação suportada via query parameters page e size
